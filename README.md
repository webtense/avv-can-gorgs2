# AVV Can Gorgs II — Web Archivística Pública

Plataforma web para la preservación y publicación del archivo histórico de la Associació de Veïns i Veïnes de Can Gorgs II (1980-2026).

## Stack

- **Frontend:** Next.js 15, React 19, TypeScript
- **Backend:** API Next.js + PostgreSQL
- **Contenedorización:** Docker + GHCR
- **CI/CD:** GitHub Actions

## Desarrollo

```bash
npm install
npm run dev
# http://localhost:3000
```
